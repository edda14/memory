# 🧠 Memory Game

An interactive memory game built with TypeScript.

## 🚀 Features

- Choose between different themes (Code / Gaming)
- Select player (Blue / Orange)
- Adjustable board sizes (16 / 24 / 36 cards)
- Card flip & match logic
- Score tracking
- Game over & winner screen

## 🛠️ Tech Stack

- TypeScript
- HTML5
- SCSS
- Vite

## ▶️ Run locally

```bash
npm install
npm run dev
